Hospital Patient Management System

Made By: Afraz Haider-72935

Objective: To create a CLI-based system that allows users to add patients, serve them/tend to them,
search for patient records by their unique IDs, update records by ID, remove records/patients from the waiting queue,
view the current waiting list of patients and the current number of patients in the list.

Coded entirely in C++.
